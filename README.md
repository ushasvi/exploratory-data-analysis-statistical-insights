# Exploratory Data Analysis & Statistical Insights

## Project Overview
This project explores retail sales data to identify patterns, relationships, and potential anomalies using Exploratory Data Analysis (EDA).

## Objectives
- Calculate descriptive statistics such as mean, median, standard deviation, and quartiles.
- Visualize data using correlation heatmaps, histograms, and box plots.
- Test three business hypotheses using statistical methods.
- Summarize five key findings based on the results.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Google Colab

## Project Workflow
1. Load and inspect the dataset.
2. Clean and prepare the data.
3. Calculate descriptive statistics.
4. Generate visualizations.
5. Test business hypotheses.
6. Document findings and conclusions.

## Results
Key findings and statistical results are documented in the Jupyter notebook.

## Dataset
This project uses a synthetic retail sales dataset created for educational purposes and statistical analysis.
